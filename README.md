FindIt - Lost and Found Web App
FindIt is a web application designed to help users post, search, and recover lost items with ease. With a clean, modern UI and category-based filters, FindIt allows users to quickly find or report lost items based on location and item details.

🚀 Live Demo
You can view the live site here:https://findlost-found.netlify.app/


📦 Features
Post and search for lost or found items

Category filters and location-based sorting

Clean, modern UI with animated backgrounds

Personalized color scheme and smooth transitions

🔧 Built With
Frontend: React Native

Backend: Node.js with MongoDB

Deployment: Netlify, GitHub
